# Mi rutina

App personal de entrenamiento (enfoque hipertrofia + handstand de complemento).
Es una página estática de un solo archivo (`index.html`): se abre desde el
celular, guarda los datos en el dispositivo y funciona sin conexión.

## Abrir la app

Publicada con GitHub Pages en:
**https://francoagnic.github.io/mi-rutina/**

### Instalarla como app en el celular
- **iPhone (Safari):** Compartir → "Agregar a inicio".
- **Android (Chrome):** menú ⋮ → "Agregar a la pantalla principal".

## Funciones
- Rutina semanal Empuje / Tirón / Piernas + 4.º día desde la semana 2.
- Registro de peso y reps por serie, con memoria de la semana anterior.
- Notas por ejercicio que se guardan y aparecen la semana siguiente.
- Timer de descanso automático al marcar cada serie.
- Tema oscuro/claro. Todo se guarda localmente (localStorage).
